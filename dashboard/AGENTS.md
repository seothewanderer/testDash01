# 대시보드 작업 지침

상위 AGENTS.md의 최소 구현·검증·국소 수정 규칙을 함께 따른다.

- 목적은 제작자의 데이터 활용 선별과 흐름 검토다. 54개 데이터를 모두 소비하는 것이 목표가 아니다.
- 산업 이해 → 직무 탐색 → 준비 역량 → 수집 공고 → 준비 로드맵을 유지한다.
- 기본 화면은 차트·분포·경로·선택 동작 중심으로 구성하고 긴 설명은 더보기로 접는다. 시각화를 늘리기 위해 근거 없는 수치나 데이터 연결을 만들지 않는다.
- 모든 데이터 활용 모듈은 `card()`로 만들고 사용 데이터, 목적, 기대효과, 연결 규칙, 한계, 검토 의견을 제공한다.
- 신규 데이터 제안은 `MISSING`에 필요한 필드·기존 ID 연결·활용 방법·목적·기대효과·수집 경로를 기록한다. 관측 결과·예시 숫자·가상 그래프를 만들지 않는다.
- 원본 CSV는 수정하지 않는다. 정정은 원문과 근거를 보존한 파생값에만 적용한다.
- 직무 사전, 실제 공고 조건, 규칙 후보, 편집 제안을 구분한다. 연결 미확인과 관측 0건과 미수집을 구분한다.
- 기업명 정확 일치 외 매핑은 별도 검토 전 적용하지 않는다. 미분류 기업을 민간으로, 방산 지정 미검증 N을 지정 아님으로 해석하지 않는다.
- 전체 키워드 빈도를 개별 공고에 연결하지 않는다. 교육 비용을 재계산하지 않는다. 연구·계약·예산을 채용으로 환산하지 않는다.
- 국방 관련 내용은 공개 업무·학습·기업 근거 수준에서 진로 탐색에 연결한다.
- 주요 파생 규칙을 바꾸면 데이터 테스트와 관련 브라우저 경로를 검증하고 `dist/index.html`을 다시 생성한다.
- 외부 서비스·CDN 없이 독립 HTML로 동작해야 한다. HTML 저장 후 선택·검토 메모가 복원되는지 확인한다.
- 로컬 결과물이다. 외부 게시·자동 수집·원본 변경은 현재 구현 범위에 포함하지 않는다.
